# Portfólio de José Luiz Neto

Site estático feito com HTML, CSS e JavaScript, sem etapa de build.

## Arquivos principais

- `index.html`: conteúdo e estrutura das seções.
- `styles.css`: temas, layout responsivo, animações e estilos visuais.
- `script.js`: alternância e persistência do tema, além do ano do rodapé.
- `assets/`: fotos, imagens dos projetos e ícones locais.

Para visualizar localmente, abra `index.html` no navegador ou use uma extensão
como Live Server no editor.
